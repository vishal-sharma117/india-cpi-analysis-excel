# India CPI Analysis Using Excel

## Project Overview
This project analyzes India's Consumer Price Index (CPI) data using Microsoft Excel to understand inflation trends and category-wise price changes.

## Objectives
- Analyze CPI category contributions.
- Study Year-on-Year (YoY) inflation trends.
- Analyze Month-on-Month (MoM) food inflation.
- Compare CPI trends before and after COVID-19.
- Explore the relationship between imported oil prices and CPI categories.

## Tools Used
- Microsoft Excel
- Excel formulas: `SUMIFS`, `AVERAGEIFS`, `IFERROR`, `EDATE`, `CORREL`

## Key Analyses
1. **CPI Category Contribution:** Compared index values across CPI categories.
2. **YoY Inflation Trend:** Examined annual changes in CPI.
3. **Food Inflation:** Identified monthly increases and decreases in food prices.
4. **COVID-19 Impact:** Compared CPI trends before and after March 2020.
5. **Oil Price Impact:** Used correlation analysis to explore relationships between imported oil prices and CPI category changes.

## Key Learnings
- Data cleaning and preparation
- Excel formula application
- Inflation trend analysis
- Correlation analysis
- Converting data into meaningful insights
